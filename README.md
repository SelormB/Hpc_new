# Monte Carlo Simulation Using the Alpine Supercomputing Cluster and Slurm

## Overview

This project demonstrates a basic Monte Carlo simulation implemented in Python and executed on the Alpine Supercomputing Cluster using the Slurm workload manager.

The project provides a practical example of a high-performance computing (HPC) workflow, including developing a statistical simulation, specifying computational resources, submitting a batch job, monitoring job execution, and saving simulation results.

## Objective

The objective was to investigate the sampling distribution of the sample mean using Monte Carlo simulation.

The simulation generated:

- **1,000 simulation replicates**
- **100 observations per replicate**
- Observations from a **standard normal distribution, N(0,1)**
- One sample mean for each replicate

A random seed of **123** was used for reproducibility.

## Statistical Simulation

For each replicate,

\[
X_1, X_2, \ldots, X_{100} \sim N(0,1)
\]

and the sample mean was calculated as

\[
\bar{X} = \frac{1}{100}\sum_{i=1}^{100}X_i.
\]

The procedure was repeated 1,000 times to obtain 1,000 simulated sample means.

For a standard normal population,

\[
E(\bar{X}) = 0
\]

and the theoretical standard error is

\[
SE(\bar{X}) = \frac{\sigma}{\sqrt{n}}
= \frac{1}{\sqrt{100}}
= 0.10.
\]

Therefore, the simulation should produce a mean of sample means close to **0** and a standard deviation of sample means close to **0.10**.

## Python Implementation

The simulation was implemented in Python.

For each of the 1,000 replicates, the program:

1. Generated 100 observations from N(0,1).
2. Calculated the sample mean.
3. Stored the sample mean.
4. Repeated the process 1,000 times.
5. Calculated summary statistics.
6. Saved the results to a CSV file.

The implementation uses Python's `random`, `statistics`, and `csv` libraries.

## HPC Workflow

The simulation was executed on the **Alpine Supercomputing Cluster** using **Slurm**.

The Slurm batch job requested:

- 1 node
- 1 task
- 1 CPU per task
- 1 GB memory
- 5-minute time limit
- CPU computing resources

The Python simulation was executed through the Slurm script using:

```bash
python3 basic_sim.py
```

The job was submitted using:

```bash
sbatch basic_sim.slurm
```

Slurm assigned the job ID:

```text
32775439
```

## Job Execution

The Slurm accounting output showed that the job completed successfully:

```text
JobID       JobName      State       Elapsed   ExitCode
32775439    basic_sim    COMPLETED   00:00:06  0:0
```

The `COMPLETED` status and exit code `0:0` indicate successful execution.

## Results

The Monte Carlo simulation produced the following results:

| Measure | Result |
|---|---:|
| Simulation replicates | 1,000 |
| Sample size per replicate | 100 |
| Mean of sample means | **0.0024** |
| SD of sample means | **0.1020** |
| Theoretical mean | **0** |
| Theoretical standard error | **0.1000** |

The simulated mean of approximately **0.0024** was very close to the theoretical population mean of **0**.

Similarly, the standard deviation of the simulated sample means was approximately **0.102**, which was close to the theoretical standard error of **0.10**.

## Interpretation

The results illustrate the sampling behavior of the sample mean.

Although individual random samples produce different sample means, repeated sampling produces a distribution centered near the true population mean.

For samples of size 100 from a standard normal population, the theoretical standard error of the sample mean is 0.10. The Monte Carlo simulation produced an empirical standard deviation of approximately 0.102, providing a close approximation to the theoretical value.

The small difference between the theoretical and simulated values is expected because the simulation uses a finite number of random samples.
